## China Legal AI

我做的项目都属于同一条中国法律 AI 主线：

```text
法律 Wiki -> legal-skills -> enterprise-legal-ops -> agent-content-workspace
知识来源      法律任务拆解      企业法务资料管理       法律人公开表达
```

这不是让 AI 替代律师。

这是把 AI 放进中国法律工作中更适合它的位置：材料读取、任务路由、来源边界、法规校验、草稿生成、出稿前审查和人工复核。
